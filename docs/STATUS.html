Apex domain

agent.forecastingpath.com is live. Railway now lists forecastingpath.com as a custom domain on oracles-agent. Cloudflare authoritative DNS has an apex A answer, but resolver caches may still return NXDOMAIN while propagation completes. See LIVE_OPERATIONS.md for checks.

Current behavior

  1. Prophet Arena calls /predict with an event and outcome labels.
  2. The endpoint runs forecast_track.predict_multi_outcome_retrieval.
  3. Brave Search evidence is deduped by domain and injected as snippets.
  4. Claude Opus 4.7 returns per-outcome probabilities.
  5. The Kalshi longshot guard floors low values at min(0.10, max(0.05, 0.5 / n_outcomes)).
  6. The endpoint returns {"probabilities": [{"market": "...", "probability": ...}]}.
